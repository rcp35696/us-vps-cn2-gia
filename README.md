## 美国VPS线路类型与价格差异

**CN2 GIA**（AS4809）：电信下一代承载网，晚高峰不掉速，电信和移动用户延迟稳定在150-180ms。适合建站、API服务。

**联通9929**（AS9929）：联通精品网络，性能接近CN2 GIA，联通用户延迟更低。部分商家配CMIN2（AS58807）照顾移动用户。

**三网直连BGP**：电信163、联通4837、移动CMI各走骨干网，不绕路但也不走精品线路。延迟比精品线路高20-30ms，价格便宜30-50%。对延迟不敏感的个人项目够用。

**住宅IP（家宽IP）**：来自真实运营商（ATT、NTT等），平台识别为普通家庭用户。TikTok、Netflix、ChatGPT这类平台对数据中心IP风控严格，住宅IP封号风险低很多。价格是数据中心IP的3-5倍。
